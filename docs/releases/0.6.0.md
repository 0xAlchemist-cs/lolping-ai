# lolPing AI 0.6.0 — draft release notes

Draft prepared on 2026-10-27. No public release has been published. Current evidence
and outstanding acceptance checks are in [release readiness](../release-readiness.md).

## English

### New features

- **Windows quick actions:** open an HTTPS website, open or activate a selected
  program, or clear desktop windows after a local wheel Ping. Actions are optional,
  off by default and have no preset bindings. Keep the original wheel images; the
  standard question mark remains reserved for AI.
- **Optional AI questions:** use your own compatible service, model and API key for
  streaming answers. On Windows, inspect screenshot previews locally and explicitly
  choose which images to send. Text-only questions do not upload screenshots;
  third-party service usage may cost money.

### Improvements and fixes

- Version 0.6.0 checks this fork's GitHub releases for updates, keeping the fork's AI
  and quick-action features on its own update channel.
- Windows login-start settings now register the installed executable and report
  failures before saving the change. Entries disabled through Windows remain
  disabled until explicitly enabled in the app.
- Repeated clearing minimizes windows each time. It does not alternate between
  showing and restoring windows.
- Windows screenshot composition and native card frames use the bundled native
  component. Installed builds load their bundled interface even when development
  environment overrides are present.

### Upgrading and compatibility

- Older 0.5.3 fork builds may still check upstream. Install this fork's installer
  manually for the first upgrade. The real Windows 0.5.3-to-0.6.0 upgrade preserved
  saved settings and the encrypted key and updated the desktop shortcut.
- Windows can refuse foreground activation. Tray programs may reopen as another
  instance, and games can require their launcher. Any administrator prompt remains
  under the user's control. Windows installers are currently unsigned.
- Windows 11 x64 is the tested platform for the new desktop actions. User checks at
  single-screen 100%, 150% and 200% and after lock/unlock passed. macOS Apple Silicon
  and experimental Linux X11 retain their platform scope; Windows actions are not
  available there. Three-platform CI is distinct from physical-machine acceptance.

Actual login start, elevated-target activation, other physical trigger/side-button
combinations, long-running stability and full physical-input latency remain open.
Mixed-monitor DPI has not been tested because no external monitor is available.
UAC prompt-return testing was waived for this delivery and has not been performed.
The tag-triggered public Release workflow has not been run.

## 简体中文

### 新功能

- **Windows 快捷动作：** 本机轮盘发出信号后，打开 HTTPS 网页、打开或唤醒所选软件，
  或一键清屏。功能默认关闭、没有预设绑定，轮盘保留原图标；标准问号始终留给 AI。
- **可选 AI 问答：** 配置自己的兼容服务、模型和 API 密钥，获取流式回答。Windows
  支持本地截图预览，由你明确选择要发送的图片；纯文字提问不上传截图。第三方服务可能收费。

### 改进与修复

- 0.6.0 从本派生版的 GitHub 发布页检查更新，让 AI 和快捷动作沿用自己的更新渠道。
- Windows 登录启动项会指向实际安装程序；系统拒绝修改时，应用会提示并保留原设置。
  在 Windows 中禁用的启动项会保持禁用，直到用户在应用中明确重新启用。
- 清屏每次都执行最小化，不再交替恢复窗口。
- Windows 截图合成和 AI 卡片原生边框改用随应用提供的原生组件；安装版即使存在开发环境
  覆盖变量，也会加载随应用提供的界面。

### 升级与兼容边界

- 旧 0.5.3 派生版可能仍在检查上游，首次升级请手动安装本派生版的安装包。真实 Windows
  0.5.3 → 0.6.0 升级已验证：原设置和加密密钥保留，桌面快捷方式更新。
- Windows 可能拒绝切到前台，托盘软件可能再次启动一个实例，游戏可能需要选择启动器。
  管理员提示由用户自行处理。目前 Windows 安装包尚未签名。
- 新桌面动作在 Windows 11 x64 验证。用户实测单屏 100%、150%、200% 和锁屏解锁后
  的相关操作均通过。macOS Apple Silicon 与实验性 Linux X11 保留各自的平台范围，
  不提供 Windows 快捷动作；三平台 CI 不等于其他平台已完成人工验收。

实际登录自启动、提权目标窗口激活、其他实体触发键和鼠标侧键组合、长时间稳定性及完整
物理输入延迟仍待验收。没有外接屏，混合 DPI 多屏尚未测试。本次交付按用户决定跳过
UAC 提示返回测试，该项未实测。按标签触发的正式 Release 工作流尚未运行。

Based on upstream [darrenprx/lolPing](https://github.com/darrenprx/lolPing) 0.5.3.
